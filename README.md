# Rock Paper Scissors Game

A browser-based **Rock Paper Scissors** game built with **HTML, CSS and JavaScript**. The player picks a move and plays against the computer, which picks randomly.

## How to Play

1. Click **Rock**, **Paper** or **Scissors**
2. The computer picks its move at random
3. The winner of the round is shown in the message below the scoreboard
4. The scoreboard keeps the score for you and the computer

### Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice means a draw

## Features

- Three clickable choices with image icons
- Random move for the computer
- Live scoreboard for the player and the computer
- Message area that shows the result of each round, starting with "Play your move"

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM manipulation, event listeners, `Math.random()`)
